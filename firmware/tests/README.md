# Tests

Tests unitarios de la fase 2, ejecutados en el PC (sin hardware), para la lógica que no depende de los periféricos:
cálculo de fecha y hora, conversión BCD del DS3231M, comparación de alarmas, máquina de estados de los menús y
antirrebote de los pulsadores.
